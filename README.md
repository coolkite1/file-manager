# 📁 文件整理助手

按 [Vibe Guide](https://rouicezar.github.io/Vibecoding-guide/zh-cn/)「桌面 App」示例制作的第一版：选择文件夹、预览整理结果、确认后复制到新位置，**原文件始终保留**。

## 三步开始

```bash
# 1. 安装依赖（首次）
npm install

# 2. 开发运行（可选）
npm start

# 3. 打包为 exe（自动生成安装包 + 便携版）
npm run dist
```

打包完成后，exe 在 `release/` 文件夹：

- `FileOrganizer-Setup-0.1.0-x64.exe` —— 安装包（装到电脑上，带桌面快捷方式）
- `FileOrganizer-Portable-0.1.0-x64.exe` —— 便携版（免安装，双击即用）

## 使用说明

1. 选择要整理的文件夹
2. 选择结果保存位置
3. 点「预览整理结果」，核对每个文件的分类与位置
4. **筛选**：点分类标签可整体过滤某类文件（如只要图片和文档）；取消勾选可排除单个文件；「全选 / 全不选」一键切换
5. 点「确认整理」，勾选的文件被复制到目标文件夹的分类子目录（图片/视频/音频/文档/压缩包/程序/其他）
6. 子文件夹里的文件也参与整理，保留原目录结构（如 `旅游/海边.jpg` → `图片/旅游/海边.jpg`）
7. 原文件始终保留；同名文件自动加序号，绝不覆盖

## 压缩解压页（第四个页签）

zip 格式（Windows 自带支持，双击就能打开）：

- **压缩**：可多选文件和文件夹 → 输出到同目录的同名 zip（自动加序号不覆盖），实时进度、可取消；
- **解压**：先预览压缩包内容（条目数与大小）→ 解压到同目录同名文件夹（自动加序号不覆盖），实时进度、可取消；
- 安全：解压带路径穿越防护（恶意压缩包里的越界条目会被跳过），兼容老工具生成的 GBK 中文文件名压缩包。

## 文档转换页（第三个页签）

PDF 与 Word 相互转换，带应用内预览：

- 选择 PDF 或 Word（.docx）文件后自动预览（PDF 逐页渲染、Word 富文本显示）；
- **Word → PDF**：保留文字、标题、表格与图片的基本排版；
- **PDF → Word**：文字版转换 —— 提取全部文字重建为 Word 文档，图片与复杂排版不保留；
- 转换结果保存在源文件同目录，同名自动加序号不覆盖；可一键预览转换结果或打开所在文件夹。

## 打包项目页（第二个页签）

不用命令行，在软件里直接打包 Electron 项目：

1. 切到「打包项目」页签，选择项目文件夹（含 package.json 的 Electron 项目）；
2. 点「检查项目」—— 自动核对 Node/npm 环境、electron/electron-builder 依赖，并按项目的 electron-builder 配置**筛选出打包所需的文件**（排除 node_modules、release 等）；
3. 点「开始打包」—— 实时显示构建日志，完成后列出生成的 exe；依赖缺失时可勾选自动 npm install。

注意：本机需已安装 Node.js；生成的 exe 在项目的 `release/` 文件夹。

## 自定义应用图标

把图标文件放进 `build/` 文件夹（任选一种）：

- `build/icon.png` —— 边长至少 256 像素的 PNG；
- `build/icon.ico` —— Windows 图标文件。

然后执行 `npm run dist` 重新打包，安装包和便携版的图标、安装界面、桌面快捷方式都会使用你的图标。不放图标文件则继续用默认图标。

## 数据与恢复

- 本工具不保存任何数据；整理结果就是目标文件夹里的文件，卸载/删除本工具不影响它们。
- 原文件只被复制、从不移动或删除。

## 常见问题

- **其他电脑提示「Windows 已保护你的电脑」**：未做代码签名，选「更多信息 → 仍要运行」。正式分发前按官方要求做代码签名（见 docs/delivery.md）。
- **`npm start` 后窗口一闪而过 / 报 ipcMain 错误**：本机环境变量里有 `ELECTRON_RUN_AS_NODE=1`（某些软件设置），会让 Electron 以纯 Node 模式运行。本项目的 `npm start` 已自动清除该变量；直接双击 exe 不受影响。若其他 Electron 程序也打不开，检查并移除这个环境变量。
- **打包失败**：删除 `node_modules`，重新 `npm install`，再 `npm run dist`。
- **想调整分类规则**：编辑 `src/main.js` 里的 `CATEGORY_RULES`。
