# 交付方案（delivery）

## 交付物（npm run dist 生成，位于 release/）

| 文件 | 用途 |
|---|---|
| `FileOrganizer-Setup-0.1.0-x64.exe` | 安装包：安装向导，可选安装位置，创建桌面快捷方式 |
| `FileOrganizer-Portable-0.1.0-x64.exe` | 便携版：免安装，双击即用 |

## 安装与使用

- 安装包：双击 → 安装向导 → 选择安装目录 → 从桌面快捷方式或开始菜单打开。
- 便携版：双击直接运行，不需要安装。

## 卸载与数据

- 安装版：Windows 设置 → 应用 → 卸载。工具本身不保存数据，整理出的文件在用户选择的目标文件夹，卸载不会删除。
- 便携版：直接删除 exe 文件即可。

## 更新方式

- 新版本重新打包后覆盖安装，或替换便携版 exe。工具不存数据，无数据迁移问题。
