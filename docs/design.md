# 技术方案说明（design）

## 结论：选什么

| 项 | 选择 |
|---|---|
| 桌面框架 | Electron（网页技术做界面，打包后是 Windows 程序） |
| 打包工具 | electron-builder（一条命令生成安装包与便携版 exe） |
| 语言 | JavaScript，界面用 HTML/CSS |

## 为什么这样选

- 本机已安装 Node.js，无需再装其他环境。
- 指南技术栈页推荐 Tauri，但 Tauri 需要 Rust 工具链，本机未安装；Electron 同样成熟，指南「桌面分发与签名」处链接的正是 Electron 官方文档。
- electron-builder 是 Electron 生态最常用的打包工具，支持 NSIS 安装包与便携版 exe 两种产物。

## 限制（需要知道）

- 未做代码签名：在其他电脑上首次运行可能出现 SmartScreen 提示（选「更多信息 → 仍要运行」）。
- 产物只保证 Windows x64。
- 应用图标暂用 Electron 默认图标（待办）。
- 第一版只在开发机验证；「另一台无开发环境的电脑安装」按指南要求仍待验证（见 release.md）。

## 数据放哪里

- 本工具不保存任何用户数据；整理结果直接写入用户选择的目标文件夹，卸载不影响文件。
- 原文件只被复制、从不修改。

## 安全设计

- 界面与系统能力隔离（contextIsolation + preload），界面代码不能直接接触文件系统。
- 文件操作只有两种：读文件列表、复制文件。没有移动、没有删除。
