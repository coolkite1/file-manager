## 环境注意事项（重要）

- 本机环境存在 `ELECTRON_RUN_AS_NODE=1` 环境变量（来源为上层进程环境，未在注册表/常见配置文件中），会让 Electron 以纯 Node 模式运行、窗口打不开。
- 项目已处理：`npm start` 走 `scripts/start.js`，启动前自动清除该变量。
- 直接双击 exe（从资源管理器启动）不受该变量影响。

## 恢复方法

- 构建失败：删除 `node_modules`，重新 `npm install && npm run dist`。
- 工具不保存数据，无数据恢复问题；原文件只被复制、从不修改。
