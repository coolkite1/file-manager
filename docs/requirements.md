# 需求说明（requirements）

> 项目：文件整理助手 —— Vibe Guide「桌面 App」示例项目
> 当前版本：0.4.0

## 给谁用

本机 Windows 用户：文件夹里文件杂乱，想按类型自动归类的人。第一版只支持 Windows。

## 解决什么问题

手动把图片/视频/文档等文件逐个分类移动耗时且容易出错；本工具先给出预览，确认后一次性完成，原文件始终保留。

## 第一版做什么（范围）

1. 选择要整理的文件夹。
2. 选择整理结果的保存位置。
3. 预览每个文件整理后的分类与位置（图片/视频/音频/文档/压缩包/程序/其他）。
4. **递归整理**：子文件夹里的文件也参与整理，保留原目录结构（如 `旅游/海边.jpg` → `图片/旅游/海边.jpg`）；符号链接/快捷方式跳过。
5. 确认后把文件**复制**到目标文件夹的分类子目录。
6. 原文件始终保留（只复制，不移动、不删除）。
7. 同名文件自动加序号（如 `报告 (2).docx`），绝不覆盖已有文件。
8. 整理中途可取消；取消与失败都有清楚提示。
9. **筛选**：预览后可按分类过滤（如只要图片和文档）、可逐个取消勾选排除文件，只有勾选的文件才会被整理。
10. **自定义图标**：把图标文件放到 `build/icon.png`（≥256×256）或 `build/icon.ico`，打包时自动使用。
11. **打包项目页**（第二个页签）：选择 Electron 项目文件夹 → 自动检查环境（Node/npm、依赖）并筛选出打包所需文件（按 electron-builder 的 files 配置，排除 node_modules 等）→ 一键执行构建 → 实时显示构建日志 → 列出生成的 exe 产物。依赖缺失时可自动 npm install。本机需已安装 Node.js。

## 第一版不做什么

- 不支持按日期、关键字等自定义规则。
- 不自动监控文件夹（需要手动操作）。
- 没有云同步、多设备、登录功能。
- 不做 macOS / Linux 安装包。

## 使用过程（从开始到结束）

打开软件 → 选源文件夹 → 选保存位置 → 预览核对 → 确认整理 → 打开结果文件夹核对。
